# Sanskar Valley Public School — Website Concept

A mobile-first single-page website concept for Sanskar Valley Public School, Panna, built by Aarunya Web Solutions.

## Files
- `index.html` — responsive landing page, inline styles and navigation.
- `assets/svps-crest.svg` — vector recreation inspired by the supplied school crest colours and motifs.

## Important before official launch
This is an independent website concept, not an official school website. The SVG crest is a recreated concept, **not the exact uploaded raster logo**. Replace it with the school-approved original logo artwork before official publication. School management should verify all claims, photos, contact details, admission information and facilities.

## Deployment
Static HTML. No build command or framework required. Deploy from the repository root on Vercel.
