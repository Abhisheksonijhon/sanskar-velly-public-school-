# Sanskar Velly Public School — website update

This package contains:
- `index.html` — revised responsive school website.
- `assets/school-event-flag-salute.webp` — optimised school event photograph.
- `assets/school-event-independence-day.webp` — optimised school event photograph.

## Install into the existing GitHub repository
Upload/replace `index.html` at the repository root.
Upload both WebP images into the existing `assets/` folder.
Keep the existing `assets/svp-logo.jpg` file; the updated page uses it.

## Before making the website official
The school should approve all admission details, class range, claims, phone numbers, address and photographs. The map is a search for the supplied address and should be checked for the exact school pin. No email address is displayed because a verified school email was not supplied.
